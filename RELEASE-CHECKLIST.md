# Release checklist
- [x] New design implemented in a separate worktree.
- [x] Original portrait and approved trophy retained.
- [x] Verified scope preserved; private source has no inaccessible links.
- [x] Native scrolling, responsive layouts and reduced-motion alternative implemented.
- [x] Production allowlist prevents legacy assets and source files from publishing.
- [x] Final browser and accessibility results recorded in QA-REPORT.md.
- [ ] Release commit pushed and hosted checks passed.
- [ ] Owner review of the actual release, including a physical phone.
- [ ] Explicit manual publication approval.
- [ ] Publish through GitHub Pages Actions.
- [ ] Verify the final HTTPS URL, assets, résumé and destinations on the hosted build.
Physical devices, browsers not covered by the test suite, external service outages and field performance cannot be certified by a local run.
